# 🚗 ECG Signal Processing and Control of Intelligent Robotic Vehicle

> **A biomedical signal-based robotic automation project**
>
> This project combines **ECG Signal Processing, Embedded Systems, and Robotics** to control a robotic vehicle using processed ECG information.

---
## 🔬 1. The Basic Idea of the Project

The main idea of this project is to take an ECG (Electrocardiogram) signal as input, process the signal, and use the extracted information to control a robotic vehicle.

> ### 💡 In Simple Terms

```text
Human ECG Signal
       ↓
Signal Processing
       ↓
Decision Making
       ↓
Robot Control
       ↓
Robot Movement
```
## 2)ECG = Electrocardiogram

An ECG is a signal that represents the electrical activity of the heart.

When the heart beats, the heart muscles generate electrical signals. Electrodes are used to detect this electrical activity from the human body.

The ECG output is generally represented as a waveform containing:

P → Q → R → S → T

The QRS complex is particularly important because it represents ventricular depolarization associated with each heartbeat.
```text
Heart
  ↓
Electrical Activity
  ↓
ECG Electrodes
  ↓
ECG Signal
  ↓
Signal Processing
```

## 4)Signal Processing?

Signal processing is the process of analyzing a raw signal and extracting useful information from it.

In this project, the basic signal-processing process can be explained in the following steps.

Step 1: Signal Acquisition

The ECG signal is collected from the human body using ECG electrodes or an ECG sensor
```text
Person
   ↓
ECG Sensor / Electrodes
   ↓
Raw ECG Signal
```
5. ECG Signal Acquisition

Signal acquisition means collecting the ECG signal from the human body.

The basic process is:
```text
Human Body → Electrodes/ECG Sensor → ECG Signal
```

The electrodes detect the electrical activity generated by the heart. The sensor or conditioning circuit then produces an electrical signal that can be processed by a controller or computer.

The quality of the acquired signal is important because a poor-quality input can affect all the later stages of the system.
6. ECG Waveform

A normal ECG waveform contains several important components.

P Wave

The P wave represents atrial depolarization.

QRS Complex

The QRS complex represents ventricular depolarization.

It is usually the most easily identifiable portion of the ECG signal.

T Wave

The T wave represents ventricular repolarization.
```text
          R
          |
     P    |       T
    /\    |      /\
   /  \   |     /  \
__/    \__|____/    \____
        Q S
```

6. Why is a Motor Driver Required?

A microcontroller generally cannot directly drive DC motors because motors require comparatively higher current than a microcontroller's output pins can provide.

Therefore, a motor driver is placed between the controller and the motors.
```text
Microcontroller
      ↓
Motor Driver
      ↓
DC Motors
```
The motor driver receives control signals from the controller and provides the required motor-driving capability.

Common motor drivers include:

L298N
L293D
TB6612FNG
